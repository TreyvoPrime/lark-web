# Lark Web browser preview

Lark Web is a Java editor with multiple files, browser-local saving, per-file undo history, search, basic code hints, formatting, Assist snippets, and project backup and restore. Use Ctrl+Space for keyword and symbol suggestions.

This preview does not compile or run Java, offer account sign-in, sync across devices, or provide desktop-only features. Browser storage can be cleared by the browser or user, so export a project backup or download individual files.

The editor uses the CodeMirror files and license under `vendor/codemirror`. Lark's full desktop app is available at https://lark.rocks/.
